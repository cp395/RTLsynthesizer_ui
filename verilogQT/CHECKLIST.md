# Tang Mega 60K FPGA UI Designer - 使用检查清单

## 构建前检查清单

### □ 步骤 1: 环境准备
- [ ] 已安装 Gowin EDA
- [ ] 已安装 Python 3.8+（可选，用于验证脚本）
- [ ] 已下载 Tang Mega 60K 原理图
- [ ] 已确认板卡型号、封装和完整 FPGA 料号（工程当前假设 GW5AT-LV60PG484A）

### □ 步骤 2: 引脚验证（最重要！）
- [ ] 已打开板卡原理图 PDF
- [ ] 已找到时钟输入引脚（CLK, OSC, XTAL）
- [ ] 已找到复位按钮引脚（KEY, RST, RESET）
- [ ] 已找到 LED 输出引脚（LED0-LED7）
- [ ] 已找到 HDMI 数据引脚（D0-D23）
- [ ] 已找到 HDMI 控制引脚（CLK, DE, HSYNC, VSYNC）
- [ ] 已找到 I2C 引脚（SCL, SDA）
- [ ] 已更新 `constraints/tang_mega_60k_hdmi.cst` 中的所有引脚

### □ 步骤 3: 时钟配置
- [ ] 已确认板卡晶振频率（□ 27 MHz  □ 50 MHz）
- [ ] 如果是 50 MHz，已更新约束文件时钟周期
- [ ] 如果是 50 MHz，已更新 PLL 配置或重新生成

### □ 步骤 4: HDMI 芯片配置
- [ ] 已确认 HDMI 芯片型号（例如：ADV7513, IT66121, ANX9134）
- [ ] 已查看芯片数据手册获取 I2C 地址
- [ ] 如果地址不是 0x39（7-bit），已更新 `rtl/adv7513_controller.v`

### □ 步骤 5: 项目验证
- [ ] 已运行验证脚本：`python verify.py`
- [ ] 所有检查项通过（7/7）
- [ ] 无错误或警告

### □ 步骤 6: 首次构建（仅 LED 测试）
- [ ] 已注释掉 HDMI 输出代码（安全起见）
- [ ] 已在 Gowin IDE 或命令行中运行综合
- [ ] 综合成功，无错误
- [ ] 已运行布局布线
- [ ] 布局布线成功，无错误
- [ ] 已生成 bitstream 文件
- [ ] 文件位置：`impl/pnr/fpga_ui_60k.fs`

### □ 步骤 7: LED 测试
- [ ] 已烧录 bitstream 到 FPGA
- [ ] LED[0] 亮起（PLL 锁定）
- [ ] LED[1] 亮起（系统运行）
- [ ] LED[6] 缓慢闪烁（帧计数器）
- [ ] 如果上述 LED 正常，继续下一步
- [ ] 如果 LED 不正常，检查时钟和复位引脚

### □ 步骤 8: 启用 HDMI（完整测试）
- [ ] 已恢复 HDMI 输出代码
- [ ] 已重新构建项目
- [ ] 已重新烧录到 FPGA
- [ ] LED[2] 在约 1 秒后亮起（HDMI 初始化）
- [ ] LED[3] 保持熄灭（无 I2C 错误）
- [ ] 已连接 HDMI 显示器
- [ ] 显示器有信号输入
- [ ] 显示内容正确（深色背景 + UI 面板）

## 故障排除清单

### □ 问题：综合失败
- [ ] 检查所有 .v 文件是否在项目中
- [ ] 检查是否有 SystemVerilog 语法
- [ ] 查看错误日志确定具体文件和行号
- [ ] 参考 README.md 故障排除章节

### □ 问题：布局布线失败
- [ ] 检查顶层模块设置（应为 top_hdmi_tang_mega_60k）
- [ ] 检查引脚约束是否有冲突
- [ ] 检查引脚是否超出封装范围
- [ ] 参考 QUICKSTART.md 常见错误表

### □ 问题：LED 都不亮
- [ ] 检查电源是否连接
- [ ] 检查 bitstream 是否正确烧录
- [ ] 检查器件选择是否正确
- [ ] 检查时钟输入引脚

### □ 问题：LED[0] 不亮（PLL 未锁定）
- [ ] 检查时钟输入引脚是否正确
- [ ] 检查时钟频率配置（27 MHz vs 50 MHz）
- [ ] 检查 PLL 参数设置
- [ ] 用示波器测量时钟信号（如有）

### □ 问题：LED[3] 亮（I2C 错误）
- [ ] 检查 I2C 引脚（SCL, SDA）是否正确
- [ ] 检查 I2C 地址是否匹配芯片
- [ ] 检查是否有上拉电阻
- [ ] 检查 HDMI 芯片型号

### □ 问题：显示器无信号
- [ ] 检查 HDMI 数据引脚（24 位 RGB）
- [ ] 检查 HDMI 时钟引脚
- [ ] 检查同步信号引脚（HSYNC, VSYNC, DE）
- [ ] 尝试不同的显示器
- [ ] 检查显示器是否支持 720p60

### □ 问题：显示异常
- [ ] 检查颜色通道顺序（RGB vs BGR）
- [ ] 检查时序参数
- [ ] 检查数据电平（3.3V）
- [ ] 检查引脚驱动能力设置
