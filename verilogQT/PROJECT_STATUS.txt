🎯 核心技术特点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 零 Framebuffer 架构
   • 传统方案: 需要 2.76 MB RAM (1280×720×3)
   • 本方案: 只需 <1 KB 状态寄存器
   • 节省: DDR3 控制器 + DMA 引擎

2. 编译型 UI 设计
   • 布局固定 → 编译为优化的硬件逻辑
   • 内容动态 → 运行时实时更新
   • 类比: 编译型语言 vs 解释型语言

3. 实时像素流生成
   • HDMI 扫描到 (x, y) → 实时计算颜色
   • 零 buffer 延迟
   • 纯组合/流水逻辑

4. 像素级验证
   • Python 和 Verilog 使用相同算法
   • 可逐像素比对验证
   • 所见即所得
